# Tokex

Low latency, high frequency, unordered, decentralized multi-party token exchange library with real-time acknowledgement

## Core Idea
`Tokens` are vital to any service layer communication regardless of the encoding properties. In a vast majority of scenarios where tokens act like a reference for the application to fetch information, the acknowledgement factor is often absent. REST API protocol ensures acknowledgement is implicit, but doesn't allow multi-casting, and this library bridges the gap.
